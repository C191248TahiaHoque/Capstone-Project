# Capstone-Project
Blockchain Based Authentication System
Proposed authentication system uses a token-based incentive mechanism to encourage active user participation and enhance trustworthy system behavior. Furthermore, authentication procedures are automated through the use of smart contract simulation, guaranteeing uniformity and transparency. The system's integration of real-time cybersecurity analytics, such as threat visualization via an interactive dashboard, login attempt tracking, and brute-force assault detection, is a significant component. A blockchain explorer with clickable block is another feature of the platform that lets users examine authentication records and confirm system functions. The system's practical viability was demonstrated by its online deployment and Flask implementation. Overall, the proposed system offers a secure, transparent, and efficient alternative to traditional authentication methods, which helps to develop decentralized identity management and cybersecurity.
